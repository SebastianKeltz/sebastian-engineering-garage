Project brief

Project brief

CAD is most useful to me when it closes the gap between an electrical design and the real object that has to hold, protect, or route it.

These parts were developed around project-specific constraints. The model is only the start; fit checks, wire clearance, fastener access, and reprinting are what turn it into usable hardware.

Engineering challenge

Create practical support parts that fit around irregular frames, batteries, wiring, and existing hardware without hiding service points or creating new interference.

Evidence map

What's proven—and what's next.

Claims are separated by evidence type so completed work, test results, simulations, and next steps stay clear.

Design method

Constraint-led modeling

  • Started from measured project geometry rather than an isolated CAD exercise.
  • Modeled around wire bends, hardware, component edges, and assembly access.
  • Used simple geometry where it made later revision faster.

Validation

Physical fit checks

  • Printed prototypes and checked the real fit against the target assembly.
  • Identified clearance and access problems that were not obvious on screen.
  • Updated dimensions and geometry for the next version.

Growing practice

Better documentation

  • Record key dimensions and revision reasons alongside each model.
  • Capture before-and-after fit photos for every iteration.
  • Track print orientation and material choices when they affect the result.

Build process

From first constraint to tested system.

A repeatable loop: isolate the problem, make the smallest useful version, observe it, and revise.

01

Measure

Capture the target geometry, neighboring components, hardware, and wire paths.

02

Model

Build the simplest geometry that solves the mounting or protection problem.

03

Print

Choose an orientation that supports the important surfaces and produces a useful prototype quickly.

04

Fit check

Test the physical part with the real frame, fasteners, battery, and wiring.

05

Revise

Change dimensions or features based on observed interference, movement, and service access.

Lessons

What changed my approach.

  • The real assembly always contains constraints the first CAD model misses.
  • Wire clearance and tool access deserve explicit design space.
  • Fast prototypes make dimension errors cheap to discover.

Next iteration

Where the project goes next.

  • Document revisions consistently
  • Capture detailed fit evidence
  • Compare material choices
  • Build a reusable project-part library
